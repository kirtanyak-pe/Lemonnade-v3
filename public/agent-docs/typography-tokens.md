# Typography tokens

> Manrope. Use one font shorthand token: `font: var(--l3-text-<role>-<size>)`, e.g. `var(--l3-text-label-12)`. Never set font-size / weight / line-height on their own.

Roles: **heading** (750) · **label** (650) · **description** (500, with paragraph spacing). Each token also has `-size`, `-weight`, `-line-height`, `-letter-spacing` and `-paragraph-spacing` parts.
